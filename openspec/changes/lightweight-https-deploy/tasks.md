## Task 1: 更新 docker-compose.yml ✓

**文件**: `docker-compose.yml`

修改现有 `docker-compose.yml`，添加：
1. `game-server` 容器内存限制（`deploy.resources.limits.memory: 600m`）及 `NODE_OPTIONS=--max-old-space-size=512` 环境变量
2. `nginx` 容器新增 `443:443` 端口映射
3. `nginx` 容器 volumes 新增 `./nginx-ssl.conf:/etc/nginx/conf.d/default.conf:ro` 和 `./certs:/etc/nginx/certs:ro`
4. 将原 nginx.conf 挂载改为 nginx-ssl.conf

最终结构：

```yaml
version: '3.9'

services:
  game-server:
    build: .
    ports:
      - '2567:2567'
    environment:
      - PORT=2567
      - NODE_ENV=production
      - NODE_OPTIONS=--max-old-space-size=512
    deploy:
      resources:
        limits:
          memory: 600m
    restart: unless-stopped

  nginx:
    image: nginx:alpine
    ports:
      - '80:80'
      - '443:443'
    volumes:
      - ./client/dist:/usr/share/nginx/html:ro
      - ./nginx-ssl.conf:/etc/nginx/conf.d/default.conf:ro
      - ./certs:/etc/nginx/certs:ro
    depends_on:
      - game-server
    restart: unless-stopped
```

## Task 2: 新增 nginx-ssl.conf ✓

**文件**: `nginx-ssl.conf`（新建）

创建支持 HTTPS 的 nginx 配置文件：

```nginx
worker_processes 1;

events {
    worker_connections 512;
}

http {
    include       /etc/nginx/mime.types;
    default_type  application/octet-stream;
    sendfile      on;

    server {
        listen 80;
        server_name _;
        return 301 https://$host$request_uri;
    }

    server {
        listen 443 ssl;
        server_name _;

        ssl_certificate     /etc/nginx/certs/server.crt;
        ssl_certificate_key /etc/nginx/certs/server.key;
        ssl_protocols       TLSv1.2 TLSv1.3;
        ssl_ciphers         HIGH:!aNULL:!MD5;

        root /usr/share/nginx/html;
        index index.html;

        location / {
            try_files $uri $uri/ /index.html;
        }

        location /colyseus/ {
            proxy_pass http://game-server:2567/;
            proxy_http_version 1.1;
            proxy_set_header Upgrade $http_upgrade;
            proxy_set_header Connection "upgrade";
            proxy_set_header Host $host;
            proxy_read_timeout 3600s;
        }
    }
}
```

> 注意：`nginx-ssl.conf` 是完整的 nginx 配置文件（含顶层 `worker_processes`、`events`、`http` 块），而非仅 `server` 块片段。需要将其挂载到 `/etc/nginx/nginx.conf` 而非 `/etc/nginx/conf.d/default.conf`，以覆盖默认配置中 `include /etc/nginx/conf.d/*.conf` 的行为。

**修正 docker-compose.yml 挂载路径**：

```yaml
volumes:
  - ./client/dist:/usr/share/nginx/html:ro
  - ./nginx-ssl.conf:/etc/nginx/nginx.conf:ro
  - ./certs:/etc/nginx/certs:ro
```

## Task 4: 新增 deploy.sh 一键部署脚本 ✓

**文件**: `deploy.sh`（新建，根目录）

创建一键部署脚本，内容如下：

```bash
#!/usr/bin/env bash
set -euo pipefail

# ===== 用户配置（仅需修改此处）=====
SERVER_IP="192.168.1.100"
# =====================================

CERTS_DIR="./certs"
CLIENT_ENV="./client/.env.production"

# 颜色输出
info()  { echo -e "\033[0;34m[INFO]\033[0m  $*"; }
ok()    { echo -e "\033[0;32m[OK]\033[0m    $*"; }
error() { echo -e "\033[0;31m[ERROR]\033[0m $*" >&2; exit 1; }

# 1. 检查依赖
info "检查依赖..."
command -v docker   >/dev/null 2>&1 || error "未找到 docker，请先安装：https://docs.docker.com/engine/install/"
command -v openssl  >/dev/null 2>&1 || error "未找到 openssl，请先安装：sudo apt install openssl"

# 兼容 docker compose v2 和 docker-compose v1
if docker compose version >/dev/null 2>&1; then
    COMPOSE="docker compose"
elif command -v docker-compose >/dev/null 2>&1; then
    COMPOSE="docker-compose"
else
    error "未找到 docker compose 或 docker-compose，请先安装"
fi
ok "依赖检查通过"

# 2. 生成自签名证书
if [ ! -f "${CERTS_DIR}/server.crt" ] || [ ! -f "${CERTS_DIR}/server.key" ]; then
    info "生成自签名 SSL 证书（有效期 10 年）..."
    mkdir -p "${CERTS_DIR}"
    openssl req -x509 -nodes -newkey rsa:2048 -days 3650 \
        -keyout "${CERTS_DIR}/server.key" \
        -out    "${CERTS_DIR}/server.crt" \
        -subj   "/CN=${SERVER_IP}" \
        -addext "subjectAltName=IP:${SERVER_IP}" \
        2>/dev/null
    ok "证书已生成：${CERTS_DIR}/server.crt"
else
    ok "证书已存在，跳过生成"
fi

# 3. 写入客户端生产环境配置
info "配置客户端 WebSocket 地址..."
echo "VITE_SERVER_URL=wss://${SERVER_IP}/colyseus" > "${CLIENT_ENV}"
ok "已写入 ${CLIENT_ENV}：VITE_SERVER_URL=wss://${SERVER_IP}/colyseus"

# 4. 构建镜像
info "构建 Docker 镜像（首次构建约需 5–8 分钟）..."
$COMPOSE build
ok "镜像构建完成"

# 5. 停止旧容器并启动新容器
info "启动服务..."
$COMPOSE down --remove-orphans 2>/dev/null || true
$COMPOSE up -d
ok "容器已启动"

# 6. 等待服务就绪
info "等待服务就绪..."
MAX_WAIT=60
WAITED=0
until curl -k -sf "https://${SERVER_IP}" >/dev/null 2>&1; do
    if [ $WAITED -ge $MAX_WAIT ]; then
        error "服务启动超时（${MAX_WAIT}s），请运行 '${COMPOSE} logs' 查看日志"
    fi
    sleep 2
    WAITED=$((WAITED + 2))
done

echo ""
echo "======================================================"
ok "部署完成！"
echo ""
echo "  访问地址：https://${SERVER_IP}"
echo "  教师端：  https://${SERVER_IP}/teacher"
echo ""
echo "  提示：首次访问时浏览器会提示证书不受信任，"
echo "        点击「高级」→「继续访问」即可。"
echo "======================================================"
```

脚本创建后执行 `chmod +x deploy.sh`。

## Task 5: 验证部署 ✓

在目标机器上（或本地模拟）执行以下验证：

1. **修改 IP**：编辑 `deploy.sh` 顶部的 `SERVER_IP`
2. **执行部署**：`./deploy.sh`
3. **验证 HTTPS**：`curl -k https://<SERVER_IP>` 返回 HTML
4. **验证 WSS**：打开浏览器访问游戏，确认 WebSocket 连接为 `wss://`（浏览器开发者工具 → Network → WS）
5. **验证内存**：`docker stats --no-stream` 确认两个容器总内存 < 800MB
6. **验证 HTTP 重定向**：`curl -I http://<SERVER_IP>` 返回 `301 Moved Permanently` 且 Location 为 `https://...`
