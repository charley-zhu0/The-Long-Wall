# 提案：长城像素建模多人协作游戏

## 摘要

开发一款面向幼儿的浏览器端3D体素（像素建模）协作游戏，以搭建和修复长城为主题。最多12名幼儿同时在线游玩，分为3组，每组4人，在各自共享的体素工作区内协作完成长城建造任务，全程由教师/管理员引导。

## 问题

幼儿需要有趣且富有教育意义的工具来培养空间想象力、动手能力和团队协作能力。现有方案要么对学前儿童过于复杂，要么缺乏实时多人协作功能，或未能提供结构化的教学支架（蓝图引导、教师监督）。

## 目标

- 提供无需安装、可在平板（触屏）和PC（鼠标/键盘）上访问的网页端体素游戏。
- 支持最多12名幼儿同时在线，实时同步、低延迟。
- 提供结构化协作任务，配备蓝图虚影引导，辅助学习。
- 为教师提供监督界面（飞行相机巡视、高亮错误位置、发送鼓励）。
- 采用适幼化UI设计：大图标、鲜艳色彩、少量文字、语音/图形提示。

## 非目标

- 移动端原生应用（iOS/Android APK）——第一阶段网页部署即可满足需求。
- 超出简单悬空检测的物理模拟——完整结构物理不在范围内。
- 跨会话的持久化存档——MVP阶段无状态房间可接受。
- 幼儿用户账号/登录——房间码由教师管理即可。

## 动机

本项目直接服务于幼儿早期教育，契合空间思维与合作学习的课程目标。基于成熟开源工具（Three.js / React Three Fiber + Colyseus）的网页端多人体素游戏开发可行，且可快速部署到学校设备，无需额外IT运维。

## 成功标准

1. 12个客户端同时在线，在校园局域网内方块放置/销毁的同步延迟 ≤ 200ms。
2. 蓝图虚影能正确标记缺失方块，并在区段完成时触发庆祝反馈。
3. 教师可通过飞行相机查看全部三个小组工作区，并发送高亮提示信号。
4. 触控操作（点击放置、长按销毁）在10英寸平板上运行正常。
5. 4–6岁幼儿无需语言引导即可理解如何放置方块（通过可用性观察验证）。
