# 提案：复杂长城修复玩法——完整-破损-完整结构

## 摘要

重新设计蓝图地图，将长城划分为三段：两侧为完整段，中间为破损待修复段，形成"完整——破损——完整"的叙事结构。破损位置以友好的虚影提示引导小朋友填补，修复完成后显示"恭喜你已经成功修复城墙！"过关提示，游戏教程中同步介绍新玩法。

## 问题

当前 `section-1.json` 蓝图是均匀分布的 20×6 城墙，服务端随机移除 30% 方块形成缺口。这种随机分布有以下问题：

1. **缺乏叙事感**：缺口随机分散，小朋友无法直观感受"哪段城墙坏了"；
2. **目标模糊**：破损区域不集中，难以形成明确的修复目标；
3. **蓝图虚影信息量不足**：当前仅显示蓝色半透明线框，对幼儿不够友好；
4. **缺少过关提示**：修复完成后没有庆祝反馈，缺乏成就感；
5. **教程未介绍修复玩法**：玩家进入前不知道有修复任务。

## 目标

- 设计新的 `section-1.json`，体现"完整左段 + 破损中段 + 完整右段"三段式结构；
- 服务端加载蓝图时，将完整段作为预置方块（不可被移除到的保护区），破损段为待修复区；
- 破损区域的蓝图虚影增强显示：添加颜色区分（黄色/橙色闪烁效果），使提示更直观；
- 修复完成时广播 `SECTION_COMPLETE`，客户端显示"恭喜你已经成功修复城墙！"庆祝弹窗；
- 教程新增一步介绍"修复破损城墙"玩法。

## 非目标

- 不引入多关卡或动态生成的破损模式（本阶段固定设计）；
- 不修改玩家移动、射线检测、或其他渲染逻辑；
- 不改变服务端房间架构或 schema 定义；
- 不添加语音提示或动画序列。

## 动机

"完整-破损-完整"的视觉结构让小朋友一眼看清任务所在区域，与随机散落缺口相比，明确的修复区域大幅降低认知负担，符合幼儿游戏设计原则。明确的过关提示和教程说明让整个游戏流程形成闭环，增强成就感和参与度。

## 成功标准

1. 游戏开始时，左右两侧长城段完整，中间段有明显缺口（约 30-40% 方块缺失）；
2. 缺失位置的蓝图虚影比当前更突出（颜色/动效有所区分）；
3. 小朋友补全中间段所有缺失方块后，出现"恭喜你已经成功修复城墙！"弹窗；
4. 教程最后一步或新增一步介绍修复玩法；
5. 完整段的预置方块不会被服务端随机移除（固定存在）。
