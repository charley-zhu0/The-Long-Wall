# 提案：重构长城元素为单一正方体

## 摘要

严格按照 `game.md` 的规格，将现有游戏中的多种砖块类型（灰砖/垛口形状/烽火台形状）和对应自定义几何体、贴图资产全部移除，改为仅使用 **1种元素——正方体（Cube）**，并依照 `game.md` 中的三视图设计全新的长城蓝图。

## 问题

现有代码中存在 3 种方块类型（`blockType 1/2/3`），分别对应灰砖、垛口（U形自定义几何体）、烽火台（三层台式自定义几何体），并引用 3 个独立贴图文件（`brick_gray.png`、`merlon.png`、`tower.png`）。这与 `game.md` 的设计背离：

- `game.md` 明确规定**基础元素只有 1 种**：尺寸为 1×1×1 的正方体
- 垛口、烽火台等结构均由正方体**堆叠排列**构成，而非特殊几何体
- 不存在"垛口贴图"或"烽火台贴图"的概念——所有方块外观一致
- 当前蓝图文件 `server/src/maps/section-1.json` 缺失，导致游戏无法正常加载蓝图

## 目标

- 移除 `blockGeometries.ts` 中的 `makeMerlonGeometry()` 和 `makeTowerGeometry()`
- 移除 `client/public/textures/merlon.png` 和 `tower.png`（保留或替换 `brick_gray.png`）
- 将 `blockStore` 中的 `BlockType = 1 | 2 | 3` 简化为单一类型
- 按照 `game.md` 的三视图（正视图/侧视图/俯视图）编写完整长城蓝图 JSON
- 蓝图包含：2个像素拱形城门 + 城墙段 + 1个烽火台，3个小组共享同一蓝图

## 非目标

- 修改网络协议、Colyseus 房间逻辑、教师界面等不相关功能
- 添加音效、粒子效果等美术打磨内容
- 更改蓝图加载机制（仍从 JSON 文件读取）

## 动机

让游戏的视觉表现与 `game.md` 中的教学设计保持一致：长城由纯正方体构建，孩子可以清晰理解每一个砖块的位置，降低认知复杂度，增强可玩性。

## 成功标准

1. 游戏中只有 1 种方块（正方体），HUD 中无多类型选择按钮（或仅保留单类型）
2. 蓝图 JSON 严格对应 `game.md` 的三视图结构，包含城门拱形和烽火台
3. 游戏启动后蓝图可正常加载，玩家可修复缺失方块并触发 `SECTION_COMPLETE`
4. 无自定义几何体残留代码，无多余贴图文件引用
